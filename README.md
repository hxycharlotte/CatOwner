This is a side-scrolling adventure game developed by a 5-person team using Pygame. Players control a cat on a quest to find its owner by exploring the world, talking to strangers, avoiding hostile dogs and geese, and collecting clues. The cat is controlled using the arrow keys, and the spacebar is used to jump.  

In the team, I was responsible for story design, progress coordination, and coding key features, including the startup screen, the game-over restart functionality, and the cat’s life system.
